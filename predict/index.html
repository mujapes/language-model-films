What this is. A bigram/trigram model — the ancestor of every language model. It learns one thing: which word tends to follow which. Transformers do something far more sophisticated, but the output is the same shape — a probability for every word in the vocabulary, sampled one token at a time.

What it shows. That fluency is a statistical property. This model has no idea what any word means, yet raise the context and it starts producing sentences. And when it has never seen a context, it has no way to say so — it falls back and guesses, confidently. That failure is a small version of a big one.
